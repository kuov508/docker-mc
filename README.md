# 翼龙面板搭建：自建 Docker 还是直接买面板服，新手开 MC 服前该搞清楚的事

搜"翼龙面板搭建"的人，其实分两类。一类想在手里的服务器上装一套 Pterodactyl——中文圈习惯叫翼龙面板——自己当运维；另一类只是想在浏览器里点几下，把服务器开起来让朋友进来玩。这两类人该看的教程不一样，花的钱也不一样，所以别急着复制命令，先确认自己属于哪一种。

下面按这两条路分别说清楚：自建要准备什么、容易在哪卡住；买现成的面板服又买到了什么；以及价格差在哪里。

## 先分清：你说的"搭建"是哪一种

翼龙面板本身是开源的，用 PHP、React 和 Go 写的游戏服务器管理面板，前端管账号和配置，后端叫 Wings，负责在 Docker 里真正跑游戏容器。阿里云甚至把它做成了轻量应用服务器的应用镜像（版本 1.11.7.1），点一下就装好。

所以"搭建"至少有两种含义：

- **自建**：你有一台 VPS 或独立服务器，自己装 Web 环境、数据库、Redis，部署前端面板，再配 Wings 节点。
- **买面板服**：服务商已经把面板搭好，你买的是"一个已经在翼龙面板里的容器"，登录面板就能开服。

自建的收益是控制权——多节点、自定义游戏配置、自己决定资源分配。代价是时间，以及出问题时得自己看日志。买面板服的收益是省事，代价是自由度受限，通常一台实例就跑一个服。

## 自建翼龙面板：环境清单和最容易卡住的几个点

### 系统与环境要求

按翼龙中国的部署文档，现在这套东西的门槛不算低，老教程里的 PHP 7.4 已经不适合新版面板了：

- **PHP 8.1 以上**，MySQL 5.7 以上（或 MariaDB 10.1.3+），外加 Redis
- Nginx 或 Apache 都行，**IIS 不建议**，官方教程明确说不提供支持
- 需要 Docker 和 `composer`，PHP 的 `fileinfo`、`redis` 等扩展要装，`putenv`、`exec`、`proc_open`、`shell_exec` 这些被宝塔默认禁用的函数得放开
- Laravel 的伪静态规则必须配置，否则页面 404

> Pterodactyl 不支持大多数 OpenVZ 架构的机器，因为它跟 Docker 不兼容。买机器装面板之前，先确认虚拟化类型是 KVM。

这条是最容易白花钱的地方——机器买完、环境装到一半才发现跑不了 Docker。

### 部署流程的骨架

不管用宝塔还是用 Docker Compose，流程大致是同一个顺序：

1. 装环境（PHP + MySQL + Redis + Nginx，或直接用 Docker 起数据库、缓存和面板三个容器）
2. 拉取面板程序，复制 `.env.example` 为 `.env`，`composer install --no-dev --optimize-autoloader`
3. 生成密钥 `php artisan key:generate --force`，这一步产生的 APP_KEY 要单独备份，丢了数据库里的加密数据就解不开
4. 按提示创建管理员账号，配置站点域名和 HTTPS
5. 创建 Wings 节点，把配置写好、注册成 systemd 服务
6. 回面板里新建游戏服务器，分配端口，开服

如果用 Docker，社区里流传的简化做法是拉一份 compose 配置和安装脚本，几条命令起容器，再用 `docker exec` 进容器创建管理员账号。看着省事，但容器网络、数据卷挂载位置、端口映射这几件事出问题时，排查难度反而比宝塔高。

### 自建需要放通的端口

- 80 / 443：面板网页
- 8080：节点守护进程通信
- 2022：SFTP 文件传输
- 25565 / 19132：Java 版和基岩版游戏端口

这也是为什么"开 15 个端口映射"这类机器规格对自建是硬需求。如果用的是 NAT 型机器，游戏端口得靠端口映射对外暴露，别指望玩家能直连内网端口。雨云的游戏云 VPS 可以加购独立公网 IP，1 个温州电信或移动单线高防 IP 60 元/月，做面板前端或者让玩家免端口号直连会省不少沟通成本。

## 买面板服：把"搭建"这件事整体外包

如果你只是想让服务器跑起来，"自建"里的第 1 到第 6 步其实都不是你真正关心的问题。雨云的思路是反过来：面板已经在那儿了，你买的是容器。

它的游戏云面板服支持一键开服的包括 Minecraft Java 版、基岩版、泰拉瑞亚和饥荒。Java 版的核心可选范围很宽——Arclight、Mohist、CatServer、Fabric、Velocity、Waterfall、Thermos、Uranium 这些都在列表里。**Forge 目前不在"一键开服"里**，得选纯 Java 环境（Docker）自己上传服务端核心，按 Forge 的安装器跑一遍 `--installServer`，再改 `run.sh` 和 `eula.txt`。这一点很多宣传页不会提，但对只是想玩整合包的人来说是决定性的。

## 计费模式：动态计费、按日计费和年付

- **按日计费**：每天从余额里扣下一天的日租，面板服专供，适合"有时候开有时候不开"的服

## 常见问题

**翼龙面板服能装 Mod 或者整合包吗？**
可以，走纯 Java 环境自己上传服务端和整合包；但 Forge 核心没有一键开服，需要手动跑安装步骤。

**面板服和 VPS 哪个更适合开服？**
只开一个服、想省事，选面板服。想同时开多个服、需要自己装环境或做端口级别的控制，选 VPS——它支持 Windows 和 Linux，可开放多个端口映射，扩展性完全不在一个层级。

**国内服务器搭面板，前端一定要域名吗？**
不一定，但用域名加 HTTPS 体验会好很多，反代时用非标准端口能避开一部分麻烦。Nginx 反向代理加 SSL 是社区教程里最通用的做法。

**数据丢了怎么办？**
自建的话，面板服的存档在数据卷里，备份靠你自己做计划任务；雨云面板服本身自带备份功能，但重要存档还是建议再往本地或对象存储同步一份。自建时那个 APP_KEY 也别忘备份。

## 怎么选：三种情况

**只想和朋友玩一个服**——直接买面板服。选翼龙或 MCSM，配置从 4核8G 起比较稳，计费模式按开服频率选动态或固定，日付先跑几天试试水。自建那套环境对你来说是纯消耗。

**手上已经有机器，想练手或者要多开**——自建。前提是确认机器是 KVM 不是 OpenVZ，然后老老实实按 PHP 8.1、MySQL 5.7、Redis 这套要求配环境，别照着三年前 PHP 7.4 的教程抄。雨云的游戏云 VPS 支持装 CentOS、Ubuntu 等系统，配合独立 IP 做面板前端，是自建路线上比较常见的组合。

**预算敏感、开服时间不固定**——把动态计费和按日计费用起来。它的设计本来就针对"峰值要性能、闲时不想花钱"的场景，用好了比同等配置的包月方案便宜不少。
